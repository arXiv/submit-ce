Case 28 — multi top-level with a blocking error in one subtree (SUBMISSION-247)

Two independent top-level TeX files; the DANGER error lives only in the subtree
of one of them:

    main_good.tex  -> \input good/intro.tex        (clean)
    main_bad.tex   -> \input bad/broken.tex         (bad/broken.tex has \bye in a
                                                     LaTeX doc -> conflicting_file_type, DANGER)

Purpose: exercise selection-aware severity (SUBMISSION-247).

Expected on Review Files:
    - Select main_bad.tex  -> the conflicting_file_type danger is in a file the
      selected top-level USES -> it BLOCKS Continue (the "Cannot continue" card).
    - Select main_good.tex -> bad/broken.tex is NOT reachable from main_good, so
      its danger is DOWNGRADED to a non-blocking warning; Continue is allowed,
      and the info nudge lists bad/broken.tex as removable.
    - Select BOTH -> bad/broken.tex is used again -> blocks.

       *file-attributed* issues; if preflight reports this at the document level

       selection -- which is itself a useful finding about 247's reach.
